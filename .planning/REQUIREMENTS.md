# Requirements: ai-toolbelt

**Defined:** 2026-03-11
**Core Value:** One repo, one install command — every custom skill, credential setup, and dev tool available on any machine, always up to date.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Plugin Packaging

- [x] **PLUG-01**: Plugin manifest with `.claude-plugin/plugin.json` and marketplace.json for private distribution
- [x] **PLUG-02**: Install script that clones repo and registers plugin in Claude Code
- [x] **PLUG-03**: Update mechanism for pulling latest changes
- [x] **PLUG-04**: Health check / doctor command that verifies all components working
- [x] **PLUG-05**: SessionStart hook that injects toolkit context

### Skill Conversion

- [x] **MIGR-01**: All 8 simple items converted to SKILL.md + frontmatter format (catchup, github-issue, github-pr, qa-description, ship-ticket, create-release-branch, daily-summary, reset-app-data)
- [ ] **MIGR-02**: All 8 complex items converted to SKILL.md + frontmatter format with supporting files (gh-upload, mobilecli, contentful-cli, create-figma-component, jira, investigate-sentry-issue, pr-description, upload-sentry-sourcemaps)
- [ ] **MIGR-03**: All `$HOME/.claude/` paths rewritten to plugin-relative paths in SKILL.md files and supporting scripts
- [x] **MIGR-04**: Inline bash/logic converted to Node.js helper scripts stored as supporting files
- [ ] **MIGR-05**: Each converted skill verified via /skill-creator benchmarking

### Credential Management

- [ ] **CRED-01**: Keychain-based setup for Jira/acli credentials
- [ ] **CRED-02**: Keychain-based setup for Sentry auth token
- [ ] **CRED-03**: Keychain-based setup for Contentful management token
- [ ] **CRED-04**: Keychain-based setup for GitHub upload credentials
- [ ] **CRED-05**: Per-skill setup.sh scripts following gh-upload pattern

### Global Config

- [ ] **CONF-01**: Global CLAUDE.md distributed via plugin

### mbridge

- [ ] **MBRD-01**: Python CLI with uv + Click, installable via `uv tool install`
- [ ] **MBRD-02**: Device discovery for iOS simulators and Android emulators
- [ ] **MBRD-03**: UI dump parsing — iOS JSON and Android XML
- [ ] **MBRD-04**: Basic interaction commands — tap, swipe, text input
- [ ] **MBRD-05**: Element finding by accessibility ID, text, XPath
- [ ] **MBRD-06**: OCR-based UI verification via pytesseract
- [ ] **MBRD-07**: mbridge SKILL.md that leverages app code knowledge and mobilecli context/cache

## v2 Requirements

### Setup & Polish

- **SETU-01**: Unified setup-all script that configures all credentials in one pass
- **SETU-02**: Credential health check that verifies all secrets present and valid
- **SETU-03**: Auto-refresh for expiring credentials

### n8n Integration

- **N8N-01**: Directory structure for n8n flow definitions
- **N8N-02**: Flow import/export scripts

### mbridge Advanced

- **MBRD-08**: App-code-aware caching for faster element resolution
- **MBRD-09**: Dump-then-OCR fallback pattern for dynamic/animated screens
- **MBRD-10**: React Native modal handling via multiple input dispatch strategies

## Out of Scope

| Feature | Reason |
|---------|--------|
| RN debugger MCP skills | Auto-generated by MCP, not custom |
| Open-source distribution | Private personal toolkit |
| MCP server for mbridge | Skill-based approach, not MCP |
| Generic/configurable skills | Work-specific is fine, private repo |
| Screenshot-based vision for mbridge | UI dumps + OCR is the approach |
