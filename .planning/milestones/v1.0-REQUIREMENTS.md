# Requirements: ai-toolbelt

**Defined:** 2026-03-11
**Core Value:** One repo, one install command — every custom skill, credential setup, and dev tool available on any machine, always up to date.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Plugin Packaging

- [x] **PLUG-01**: Plugin manifest with `.claude-plugin/plugin.json` and marketplace.json for private distribution
- [x] **PLUG-02**: Install script that clones repo and registers plugin in Claude Code
- [x] **PLUG-03**: Update mechanism for pulling latest changes
- [x] **PLUG-04**: Health check / doctor command that verifies all components working
- [x] **PLUG-05**: SessionStart hook that injects toolkit context

### Skill Conversion

- [x] **MIGR-01**: All 8 simple items converted to SKILL.md + frontmatter format (catchup, github-issue, github-pr, qa-description, ship-ticket, create-release-branch, daily-summary, reset-app-data)
- [x] **MIGR-02**: All 8 complex items converted to SKILL.md + frontmatter format with supporting files (gh-upload, mobilecli, contentful-cli, create-figma-component, jira, investigate-sentry-issue, pr-description, upload-sentry-sourcemaps)
- [x] **MIGR-03**: All `$HOME/.claude/` paths rewritten to plugin-relative paths in SKILL.md files and supporting scripts
- [x] **MIGR-04**: Inline bash/logic converted to Node.js helper scripts stored as supporting files
- [x] **MIGR-05**: Each converted skill verified via /skill-creator benchmarking

### Credential Management

- [x] **CRED-01**: Keychain-based setup for Jira/acli credentials
- [x] **CRED-02**: Keychain-based setup for Sentry auth token
- [x] **CRED-03**: Keychain-based setup for Contentful management token
- [x] **CRED-04**: Keychain-based setup for GitHub upload credentials
- [x] **CRED-05**: Per-skill setup.sh scripts following gh-upload pattern

### Global Config

- [x] **CONF-01**: Global CLAUDE.md distributed via plugin

### mbridge

- [x] **MBRD-01**: Python CLI with uv + Click, installable via `uv tool install`
- [x] **MBRD-02**: Device discovery for iOS simulators and Android emulators
- [x] **MBRD-03**: UI dump parsing — iOS JSON and Android XML
- [x] **MBRD-04**: Basic interaction commands — tap, swipe, text input
- [x] **MBRD-05**: Element finding by accessibility ID, text, XPath
- [x] **MBRD-06**: OCR-based UI verification via pytesseract
- [x] **MBRD-07**: mbridge SKILL.md that leverages app code knowledge and mobilecli context/cache

### Per-Organization Credential Scoping

- [x] **SCOPE-01**: Org extraction from git remote URL (SSH, HTTPS, ssh:// formats)
- [x] **SCOPE-02**: Org-aware credential resolution with global fallback (resolve-credential.js)
- [x] **SCOPE-03**: Setup scripts auto-detect org and store to scoped Keychain key
- [x] **SCOPE-04**: --global flag on setup scripts to bypass org scoping
- [x] **SCOPE-05**: API scripts (sentry-api.js, github-api.js) use org-aware resolution
- [x] **SCOPE-06**: SKILL.md auto-detect and runtime retrieval use resolve-credential.js
- [x] **SCOPE-07**: Doctor credential checks report org-scoped vs global vs missing status
- [x] **SCOPE-08**: One-time migration script copies global credentials to org-scoped keys

### Android Emulator Boot + Device Hardening

- **BOOT-01**: Android AVD discovery via `emulator -list-avds` with `--available` flag on `device list`
- **BOOT-02**: Android emulator boot with GPU host-to-software fallback (requires emulator 36.4.9+)
- **BOOT-03**: Boot-wait polling via `adb shell getprop sys.boot_completed` with configurable timeout
- **BOOT-04**: iOS simulator boot opens Simulator.app GUI window
- **BOOT-05**: `device boot` propagates RuntimeError instead of silently swallowing errors
- **BOOT-06**: `swipe-to` extra swipe when element center is outside usable zone (middle 80% of screen)
- **BOOT-07**: SKILL.md updated with Android emulator boot documentation

## v2 Requirements

### Setup & Polish

- **SETU-01**: Unified setup-all script that configures all credentials in one pass
- **SETU-02**: Credential health check that verifies all secrets present and valid
- **SETU-03**: Auto-refresh for expiring credentials

### n8n Integration

- **N8N-01**: Directory structure for n8n flow definitions
- **N8N-02**: Flow import/export scripts

### mbridge Advanced

- **MBRD-08**: App-code-aware caching for faster element resolution
- **MBRD-09**: Dump-then-OCR fallback pattern for dynamic/animated screens
- **MBRD-10**: React Native modal handling via multiple input dispatch strategies

## Out of Scope

| Feature | Reason |
|---------|--------|
| RN debugger MCP skills | Auto-generated by MCP, not custom |
| Open-source distribution | Private personal toolkit |
| MCP server for mbridge | Skill-based approach, not MCP |
| Generic/configurable skills | Work-specific is fine, private repo |
| Screenshot-based vision for mbridge | UI dumps + OCR is the approach |
