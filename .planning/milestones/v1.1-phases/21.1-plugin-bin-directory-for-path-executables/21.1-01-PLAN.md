  <action>
Create `bin/` directory at project root.

For each wrapper, use this exact pattern (two variants):

**Node.js scripts** (forgetful-client, gsd-plan-context, gsd-project-context, gsd-discuss-context, gsd-milestone-save):
```bash
#!/usr/bin/env bash
exec node "$(dirname "$0")/../scripts/{SCRIPT_NAME}.js" "$@"
```

**Bash scripts** (git-base-branch, git-diff-filtered, git-identity):
```bash
#!/usr/bin/env bash
exec bash "$(dirname "$0")/../scripts/{SCRIPT_NAME}.sh" "$@"
```

Mapping:
- `bin/forgetful-client` -> `exec node "$(dirname "$0")/../scripts/forgetful-client.js" "$@"`
- `bin/git-base-branch` -> `exec bash "$(dirname "$0")/../scripts/git-base-branch.sh" "$@"`
- `bin/git-diff-filtered` -> `exec bash "$(dirname "$0")/../scripts/git-diff-filtered.sh" "$@"`
- `bin/git-identity` -> `exec bash "$(dirname "$0")/../scripts/git-identity.sh" "$@"`
- `bin/gsd-plan-context` -> `exec node "$(dirname "$0")/../scripts/gsd-plan-context.js" "$@"`
- `bin/gsd-project-context` -> `exec node "$(dirname "$0")/../scripts/gsd-project-context.js" "$@"`
- `bin/gsd-discuss-context` -> `exec node "$(dirname "$0")/../scripts/gsd-discuss-context.js" "$@"`
- `bin/gsd-milestone-save` -> `exec node "$(dirname "$0")/../scripts/gsd-milestone-save.js" "$@"`

After creating all files, run: `chmod +x bin/*`

Do NOT use symlinks (plugin cache system copies files; wrappers are more explicit and debuggable per research).
Do NOT move scripts to bin/ directly (scripts/ remains canonical source per research).
