  <action>
Create `bin/curate-discoveries` as a Node.js executable script (NOT a wrapper -- this is new logic, not a delegation).

Shebang: `#!/usr/bin/env node`

The script reads SubagentStop hook input from stdin (JSON) and also finds RESEARCH.md on disk as a fallback. It parses General Discoveries, dedup-checks each against Forgetful, and saves qualifying entries.

**Script flow:**

1. Read stdin as JSON. Extract `last_assistant_message` and `cwd` fields. If stdin is empty or not JSON, log to stderr and exit 0.

2. Parse `## General Discoveries` section from `last_assistant_message`. Use regex: `/## General Discoveries\n([\s\S]*?)(?=\n## [^#]|\n---|\Z)/`

3. If no General Discoveries section found in `last_assistant_message`, try fallback: glob `${cwd}/.planning/phases/*-RESEARCH.md`, sort by mtime descending, read the most recent one, parse from that.

4. If still no General Discoveries section found, log `"No General Discoveries section found"` to stderr and exit 0.

5. Parse individual discovery entries from the section. Each entry starts with `###` and contains **Title:**, **Content:**, **Scope:**, **Domain:**, **Confidence:**, **Tags:** fields. Use these regexes:
   - title: `/\*\*Title:\*\*\s*(.+)/`
   - content: `/\*\*Content:\*\*\s*([\s\S]*?)(?=\*\*Scope)/`
   - scope: `/\*\*Scope:\*\*\s*(.+)/`
   - domain: `/\*\*Domain:\*\*\s*(.+)/`
   - confidence: `/\*\*Confidence:\*\*\s*(.+)/`
   - tags: `/\*\*Tags:\*\*\s*(.+)/` -- split on commas, trim each

6. For each parsed entry with at least title and content:
   a. Run dedup check: spawn `forgetful-client call-tool query_memory '{"query": "<TITLE>", "k": 3}'` using `child_process.execFileSync`. Parse JSON output. If any result has a title that closely matches (case-insensitive substring match of >80% of words), skip as duplicate. Log to stderr: `"SKIP (duplicate): <title>"`.
   b. If not duplicate, create memory: spawn `forgetful-client call-tool create_memory` with JSON args:
      ```json
      {
        "title": "<parsed title>",
        "content": "<parsed content>",
        "metadata": {
          "scope": "<parsed scope>",
          "domain": "<parsed domain>",
          "confidence": "<parsed confidence>",
          "tags": "<parsed tags as comma-separated string>",
          "source": "gsd-research-auto-curation",
          "created_by": "curate-discoveries"
        }
      }
      ```
      Log to stderr: `"SAVED: <title>"`

7. Write summary to stdout: `"Curated N discoveries: M saved, K skipped (duplicate)"`

**Support --dry-run flag:** If `process.argv.includes('--dry-run')`, read from stdin, parse discoveries, log what WOULD be saved/skipped to stderr, but do NOT actually call forgetful-client for create_memory. Still do the dedup query to show what would happen.

**Error handling:** Wrap the entire flow in try/catch. On any error, log to stderr and exit 0 (non-blocking -- must never crash the main session).

**Resolve forgetful-client path:** Use `path.join(path.dirname(process.argv[1]), 'forgetful-client')` to find the sibling bin/ script, OR use `path.join(__dirname, '..', 'scripts', 'forgetful-client.js')` and invoke with node directly. Either works since both are in the same bin/ directory.

After creating, run: `chmod +x bin/curate-discoveries`

Add a `SubagentStop` entry to the existing hooks.json. The final file must be valid JSON:

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "startup|resume|clear|compact",
        "hooks": [
          {
            "type": "command",
            "command": "${CLAUDE_PLUGIN_ROOT}/hooks/session-start.sh",
            "async": true
          }
        ]
      }
    ],
    "SubagentStop": [
      {

      }

  }
}
```

- `timeout: 120` -- 2 minute timeout for dedup queries + saves
