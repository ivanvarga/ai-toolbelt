Create 5 bash patch scripts. Each follows the idempotency guard pattern from research:
1. Check workflow file exists (SKIP if missing -- GSD not installed)
2. Check TB_PATCH marker already present (SKIP if already patched)
3. Create temp file with content to insert
4. Use `sed -i '' "/MARKER/r $TMPFILE"` to insert after the marker line (BSD sed with empty backup extension)
5. Clean up temp file
6. Echo status

**CRITICAL:** Use `sed -i ''` (BSD sed, macOS). Use `/r $TMPFILE` approach for multi-line insertions to avoid sed special character issues (Pitfall 2 from research). Each patch script resolves `PLUGIN_ROOT="$(cd "$(dirname "$0")/.." && pwd)"` for the tb plugin root.

**PLUGIN_ROOT in patched content:** The inserted bash blocks need PLUGIN_ROOT at workflow runtime. Since GSD workflows don't know about tb's plugin path, the patch script must resolve the absolute path at apply-time and embed it as a literal string in the inserted content. Use `$PLUGIN_ROOT` (resolved by the patch script's own context) when writing the temp file content.

- If edit: let user modify content, then save
- If skip: move to next candidate

**Step 4: Summary**
Display count of saved/skipped/obsoleted memories.

</step>
```
