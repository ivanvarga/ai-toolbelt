`# Bootstrap` followed by a one-line description: "Set up the complete tb integration environment: GSD, forgetful-plugin, and GSD workflow patches."

**Steps (5 total):**

**Step 1: Resolve plugin root**
```bash
PLUGIN_ROOT="${CLAUDE_SKILL_DIR}/../.."
```

**Step 2: Check and install GSD**
Run the doctor check:
```bash
GSD_RESULT=$(bash "$PLUGIN_ROOT/scripts/checks/gsd-installed.sh" "$PLUGIN_ROOT")
echo "$GSD_RESULT"
```
- If output starts with `PASS`: report "GSD: already installed" with the version extracted from the message (everything after "GSD "), and continue to step 3.
- If output starts with `FAIL`: Per D-01, tell the user to run GSD's install command manually: `npx -y get-shit-done-cc@latest --claude --global`. Explain that GSD's installer may have interactive prompts so it must be run by the user. Per D-02, after the user reports completion, re-run the check script. If still FAIL, inform the user and ask to retry or skip.

**Step 3: Check and install forgetful-plugin**
First, check if forgetful-plugin is already installed by looking for its key in `~/.claude/plugins/installed_plugins.json`:
```bash
INSTALLED_FILE="$HOME/.claude/plugins/installed_plugins.json"
if [ -f "$INSTALLED_FILE" ] && jq -e '.plugins["forgetful-plugin@forgetful-plugins"]' "$INSTALLED_FILE" >/dev/null 2>&1; then
  FP_VERSION=$(jq -r '.plugins["forgetful-plugin@forgetful-plugins"][0].version' "$INSTALLED_FILE")
  echo "forgetful-plugin: already installed (v${FP_VERSION})"
else
  echo "forgetful-plugin: not found, installing..."
fi
```
- If already installed (jq succeeds): report "forgetful-plugin: already installed (v{VERSION})" per D-10, continue to step 4.
- If not installed (jq fails or file missing): Per D-04/D-05, install via `claude plugin install forgetful-plugin@forgetful-plugins --scope user`. This CLI command handles git clone internally from marketplace config, satisfying both D-04 (git-based install) and D-05 (discovers from settings). After install, verify by re-checking the installed_plugins.json. If verification fails, report error with guidance.

NOTE: Do NOT use the `forgetful-plugin.sh` doctor check for detection in bootstrap, because that script's jq query (`.[] | select(.id == ...)`) does not correctly parse the v2 dict format of installed_plugins.json. Instead, use the direct jq query `.plugins["forgetful-plugin@forgetful-plugins"]` shown above. The doctor check remains useful for `/tb:doctor` display but not for programmatic detection.

**Step 4: Apply GSD patches**
Per D-11, always run regardless of prior state (patches are idempotent):
```bash
bash "$PLUGIN_ROOT/patches/apply-all.sh"
```
Only run this step if GSD is installed (step 2 resulted in PASS). If GSD is not installed, skip and note that patches require GSD.

**Step 5: Summary**
Report final status of all three components:
- GSD: installed (v{X.Y.Z}) or not installed
- forgetful-plugin: installed (v{X.Y.Z}) or not installed
- GSD patches: {N} applied, {M} errors (from apply-all.sh output) or skipped (GSD not installed)

If all components are healthy, report "Bootstrap complete -- all components ready."
If any component failed, list what needs attention.
