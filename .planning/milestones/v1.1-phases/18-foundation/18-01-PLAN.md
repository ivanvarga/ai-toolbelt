Protocol version: 2025-03-26

Create scripts/forgetful-client.js as a CommonJS Node.js module (per D-03) with these exact exports:

1. `resolveForgetfulUrl()` — Reads `~/.claude.json`, returns `config.mcpServers.forgetful.url` or null. Path: `path.join(process.env.HOME, '.claude.json')`. Parse with `JSON.parse(fs.readFileSync(configPath, 'utf8'))`. Return null (not throw) if file missing or key absent.

2. `createSession(url)` — Async. Performs MCP initialize + notifications/initialized handshake:
   - POST to `url` with JSON-RPC body: `{"jsonrpc":"2.0","method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"tb-client","version":"0.1.0"}},"id":1}`
   - Headers: `Content-Type: application/json` AND `Accept: application/json, text/event-stream` (both required per D-02, Pitfall 2)
   - Extract session ID from response header: `res.headers.get('mcp-session-id')` (lowercase per HTTP/1.1, Pitfall 3)
   - Send initialized notification: POST with `{"jsonrpc":"2.0","method":"notifications/initialized"}` and `Mcp-Session-Id: <sessionId>` header. This returns HTTP 202 with no body.
   - Use `AbortSignal.timeout(5000)` on both fetch calls
   - Return `sessionId` string

3. `callTool(url, sessionId, toolName, args)` — Async. Calls MCP tools/call:
   - POST with JSON-RPC body: `{"jsonrpc":"2.0","method":"tools/call","params":{"name":toolName,"arguments":args},"id":2}`
   - Include `Mcp-Session-Id: <sessionId>` header
   - Response is SSE (`text/event-stream`), NOT JSON. Use `res.text()` (NOT `res.json()` -- Pitfall 1)
   - Parse SSE: split text by newlines, find line starting with `data: `, extract JSON after prefix with `JSON.parse(line.slice(6))`
   - `AbortSignal.timeout(10000)` (tool calls may take longer)
   - Return parsed JSON-RPC result object

4. `healthCheck(url)` — Async. Convenience function:
   - Call `createSession(url)`, if succeeds return `{ ok: true, sessionId }`
   - On error, return `{ ok: false, error: err.message }`

5. CLI mode (`require.main === module` guard):
   - Subcommand `health`: call `resolveForgetfulUrl()`, if null write "Forgetful URL not configured in ~/.claude.json\n" to stderr and exit 1. Otherwise call `healthCheck(url)`, write result as JSON to stdout.
   - Subcommand `resolve-url`: call `resolveForgetfulUrl()`, write URL to stdout or "not configured\n" to stderr + exit 1.
   - No subcommand or unknown: write "Usage: forgetful-client.js <health|resolve-url>\n" to stderr, exit 1.
