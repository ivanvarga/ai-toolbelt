<threat_model>
ASVS L1 threats relevant to this plan (cleanup — touches filesystem via `git worktree remove`):

1. **`git worktree remove` with attacker-controlled path** — if PR payload `pull_request.head.ref` is attacker-controlled (anyone opening a PR can set branch name) and reaches a shell without validation, RCE via `$()` injection. Mitigation: `cleanup.js` NEVER shells out with payload data. Worktree path is derived from dedup-store entry (stored at relay-time from already-validated dedup key) and passed to `git worktree remove --force` via `child_process.execFile` (array args, no shell interpolation).
2. **Mismatched cleanup** — an attacker-controlled PR for repo X with a `head.ref` crafted to match a worktree name for repo Y could delete Y's worktree. Mitigation: match PR via dedup-store entry where `paperclipIssueId` or stored `prUrl` is the trusted anchor. Only clean up if `pull_request.html_url` matches stored `prUrl` OR if `pull_request.head.ref === 'worktree-' + storedWorktreeName` AND the PR's `repository.full_name` matches the dedup key's owner/repo component.
3. **Cleanup recoverability** — if `git worktree remove` fails partway, state is inconsistent. Mitigation: remove dedup entry LAST, AFTER worktree removal confirms. On worktree-remove failure, log error, leave dedup entry intact so a human can retry manually.
4. **Race with executing agent** — cleanup fires while the coder agent is still running in the worktree. Mitigation: use `git worktree remove --force` (documented in 24-RESEARCH.md §Claude Code Worktree Mechanism as acceptable for headless flows). The human approval gate is upstream of cleanup, so by the time PR is merged, coder agent has already completed and transitioned to `done`. In practice: no race; mitigation is the `--force` belt-and-suspenders.

Severity: MEDIUM (filesystem mutation driven by webhook). Gate: pass iff all 4 mitigations present and tested.
</threat_model>

    `scripts/tb-triage/cleanup.js`:
    ```js
    const path = require('node:path');
    const { execFile } = require('node:child_process');
    const { promisify } = require('node:util');
    const dedup = require('./dedup-store');

    const pExecFile = promisify(execFile);

    function matchDedupKeyFromPr(payload, entries) {
      const prUrl = payload?.pull_request?.html_url;
      const headRef = payload?.pull_request?.head?.ref;
      const fullName = payload?.repository?.full_name;

      if (prUrl) {
        for (const [key, entry] of Object.entries(entries)) {
          if (entry?.prUrl === prUrl) return key;
        }
      }

      if (headRef && headRef.startsWith('worktree-gh-') && fullName) {
        const expectedPrefix = `gh:${fullName}#`;
        for (const [key, entry] of Object.entries(entries)) {
          if (key.startsWith(expectedPrefix) && entry?.worktreeName && headRef === `worktree-${entry.worktreeName}`) {
            return key;
          }
        }
      }

      return null;
    }

    async function removeWorktreeForPr(payload, options = {}) {
      const dedupStore = options.dedupStore || dedup;
      const gitExec = options.gitExec || (async (args, opts) => pExecFile('git', args, opts));

      const entries = dedupStore.list();
      const key = matchDedupKeyFromPr(payload, entries);
      if (!key) {
        return { cleaned: false, reason: 'no dedup entry matches pr' };
      }

      const entry = entries[key];
      if (!entry?.worktreeCwd || !entry?.worktreeName) {
        dedupStore.remove(key);
        return { cleaned: true, key, worktreeName: null, reason: 'dedup entry had no worktree; removed entry only' };
      }

      const parentRepo = entry.worktreeCwd.replace(/\/\.claude\/worktrees\/[^/]+\/?$/, '');
      if (parentRepo === entry.worktreeCwd) {
        return { cleaned: false, reason: 'worktreeCwd not under .claude/worktrees/', key };
      }

      try {
        await gitExec(['-C', parentRepo, 'worktree', 'remove', '--force', entry.worktreeName]);
      } catch (err) {
        return { cleaned: false, reason: 'git worktree remove failed', error: err.message, key };
      }

      dedupStore.remove(key);
      return { cleaned: true, key, worktreeName: entry.worktreeName };
    }

    module.exports = { matchDedupKeyFromPr, removeWorktreeForPr };
    ```
