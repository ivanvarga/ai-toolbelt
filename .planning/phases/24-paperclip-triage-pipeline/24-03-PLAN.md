<threat_model>
ASVS L1 threats relevant to this plan (webhook intake + outbound re-sign — the CORE security surface of Phase 24):

1. **HMAC timing attack (inbound)** — comparing signatures with `===` leaks byte-level match timing. Mitigation: use `crypto.timingSafeEqual` verbatim in `relay-filters.js` (re-export Wave 0 `hmac.js` helpers verified). Test: verify with tampered signature returns `false` in constant time (we only unit-test the boolean — timing invariance is delegated to Node's `timingSafeEqual`).
2. **Raw-body tampering across parsing** — if HTTP handler parses JSON BEFORE HMAC verify, body re-serialization changes bytes and HMAC fails legitimately (false rejection) or, worse, verifies against a mutated body (acceptance of tampered). Mitigation: handler captures `req` chunks into `rawBody` Buffer, verifies HMAC against `rawBody`, THEN `JSON.parse(rawBody)`. Tests verify this by passing a body with extra whitespace that still verifies correctly.
3. **Replay attack on outbound Paperclip fire** — no timestamp check means a captured request can be replayed. Mitigation: `fireRoutine` includes current `Math.floor(Date.now() / 1000)` in `X-Paperclip-Signature`; Paperclip side rejects stale timestamps (> 5 min). Test: round-trip with verifyPaperclip using `maxAgeSeconds: 300` accepts fresh, rejects timestamp 400s old.
4. **Re-sign key compromise via logs** — if relay logs inbound body on error with Keychain-sourced secrets in env, secrets leak. Mitigation: relay NEVER logs the secret itself, only the service key name; error branches log event type + status code only; stack traces sanitized by removing `Authorization`/`X-Paperclip-Signature`/`X-Hub-Signature-256` headers before emit.
5. **Path injection via issue body / title / labels** — if a triage tag `triage:skip; rm -rf /` reaches a shell, RCE. Mitigation: filter functions are pure JS string comparison only; no shell escape; tag matching uses `labels.some(l => l.name === 'triage:skip')` — strict equality, no `includes` matching.
6. **Dedup-key path traversal** — already mitigated in Plan 02 (dedup-store rejects non-matching KEY_PATTERN). Relay enforces by calling `buildDedupKey` which itself applies the same regex at construction.
7. **DoS via large body** — untrusted webhook bodies can be huge. Mitigation: relay rejects requests with `content-length > 1048576` (1 MB) with HTTP 413. GitHub webhooks cap at 25 MB but normal assignment payload is ~5 KB; 1 MB is generous.
8. **Open redirect via `html_url`** — if relay follows a URL from payload for any reason, attacker controls destination. Mitigation: relay NEVER dereferences issue URLs; only serializes them into Paperclip fire body as strings.

9. **Cross-plan consistency (B1/B2) — no bypass path anywhere.** relay.js enforces strict `verifyGithubSignature` / `verifyJiraSignature` on every inbound webhook; there is NO `SKIP_VERIFY` sentinel, feature flag, or env-var switch that disables verification. The Plan 07 setup doc's Jira "Option B" (Automation-for-Jira) is DEV ONLY behind a smee.io tunnel and cannot actually bypass the relay — Automation-for-Jira's unsigned traffic will receive 401 from the relay until either Option A (native Jira webhooks with HMAC) is used or a dev-side signing proxy replays with the seeded `jira_webhook_secret`. This is the documented cross-plan contract: Plan 03 owns the enforcement; Plan 07 documents the constraint; no plan provides a bypass.

Severity: HIGH (public webhook-facing surface + HMAC crypto). Gate: pass iff all 9 mitigations implemented and tests cover #1-#5.
</threat_model>

    ```js
    const crypto = require('node:crypto');
    const { KEY_PATTERN } = require('./dedup-store');

    const TAG_VOCAB = { 'triage:oneshot': 'oneshot', 'triage:process': 'process', 'triage:skip': 'skip' };

    function verifyGithubSignature(rawBody, header, secret) {
      if (!header || !header.startsWith('sha256=')) return false;
      const expected = 'sha256=' + crypto.createHmac('sha256', secret).update(rawBody).digest('hex');
      try { return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(header)); } catch { return false; }
    }

    function verifyJiraSignature(rawBody, header, secret) {
      return verifyGithubSignature(rawBody, header, secret);
    }

    function extractTriageTag(labels) {
      if (!Array.isArray(labels)) return null;
      for (const l of labels) {
        const name = typeof l === 'string' ? l : l?.name;
        if (name && TAG_VOCAB[name]) return TAG_VOCAB[name];
      }
      return null;
    }

    function buildDedupKey(event, payload) {
      if (event === 'issues' && payload?.repository?.full_name && payload?.issue?.number != null) {
        const key = `gh:${payload.repository.full_name}#${payload.issue.number}`;
        if (!KEY_PATTERN.test(key)) throw new Error(`built invalid dedup key: ${key}`);
        return key;
      }
      if (event === 'jira:issue_updated' && payload?.issue?.key) {
        const key = `jira:${payload.issue.key}`;
        if (!KEY_PATTERN.test(key)) throw new Error(`built invalid dedup key: ${key}`);
        return key;
      }
      throw new Error(`cannot build dedup key for event ${event}`);
    }

    function shouldRelayGithub(event, payload, config) {
      if (event === 'pull_request') {
        if (payload?.action === 'closed' && payload?.pull_request?.merged === true) {
          return { relay: true, reason: 'pr merged cleanup', dedupKey: null };
        }
        return { relay: false, reason: 'pr action not cleanup-relevant' };
      }
      if (event !== 'issues') return { relay: false, reason: `unsupported event: ${event}` };

      const action = payload?.action;
      const assigneeLogin = payload?.assignee?.login || payload?.issue?.assignee?.login;

      if (action === 'assigned') {
        if (assigneeLogin !== config.triageUserLogin) {
          return { relay: false, reason: 'assignee mismatch' };
        }
        return { relay: true, reason: 'issues.assigned to ' + assigneeLogin, dedupKey: buildDedupKey('issues', payload) };
      }

      if (action === 'labeled') {
        const tag = extractTriageTag(payload?.issue?.labels || []);
        if (!tag) return { relay: false, reason: 'label not in triage vocabulary' };
        return { relay: true, reason: `tag override: ${tag}`, dedupKey: buildDedupKey('issues', payload) };
      }

      return { relay: false, reason: 'action not triaged' };
    }

    function shouldRelayJira(payload, config) {
      if (payload?.webhookEvent !== 'jira:issue_updated') {
        return { relay: false, reason: `unsupported jira event: ${payload?.webhookEvent}` };
      }

      const items = payload?.changelog?.items || [];

      const labelItem = items.find(i => i.field === 'labels');
      if (labelItem) {
        const tag = extractTriageTag(payload?.issue?.fields?.labels || []);
        if (tag) return { relay: true, reason: `tag override: ${tag}`, dedupKey: buildDedupKey('jira:issue_updated', payload) };
      }

      const assigneeChange = items.find(i => i.field === 'assignee' && i.to === config.triageUserAccountId);
      if (assigneeChange) {
        return { relay: true, reason: 'assignee changelog matches', dedupKey: buildDedupKey('jira:issue_updated', payload) };
      }

      return { relay: false, reason: 'no assignee change in changelog' };
    }

    module.exports = { verifyGithubSignature, verifyJiraSignature, extractTriageTag, buildDedupKey, shouldRelayGithub, shouldRelayJira, TAG_VOCAB };
    ```

    `scripts/tb-triage/relay-paperclip-client.js`:

    ```js
    const crypto = require('node:crypto');

    function signPaperclip(timestamp, body, secret) {
      const mac = crypto.createHmac('sha256', secret).update(`${timestamp}.${body}`).digest('hex');
      return `t=${timestamp},v1=${mac}`;
    }

    async function withTimeout(promise, ms, label) {
      const ac = new AbortController();
      const t = setTimeout(() => ac.abort(), ms);
      try { return await promise(ac.signal); }
      finally { clearTimeout(t); }
    }

    async function fireRoutine(publicId, bodyObject, { apiBase, signingKey }) {
      const rawBody = JSON.stringify(bodyObject);
      const timestamp = Math.floor(Date.now() / 1000);
      const signature = signPaperclip(timestamp, rawBody, signingKey);
      const url = `${apiBase}/api/routine-triggers/public/${encodeURIComponent(publicId)}/fire`;

      const res = await withTimeout((signal) => fetch(url, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          'x-paperclip-signature': signature,
        },
        body: rawBody,
        signal,
      }), 10000, 'fireRoutine');

      if (!res.ok) {
        const text = await res.text().catch(() => '');
        const err = new Error(`paperclip fire rejected: HTTP ${res.status}`);
        err.cause = text.slice(0, 500);
        throw err;
      }
      return res.json();
    }

    async function listProjects({ apiBase, apiKey, companyId }) {
      const url = `${apiBase}/api/companies/${encodeURIComponent(companyId)}/projects`;
      const res = await withTimeout((signal) => fetch(url, {
        headers: { 'authorization': `Bearer ${apiKey}` },
        signal,
      }), 10000, 'listProjects');
      if (!res.ok) throw new Error(`paperclip listProjects: HTTP ${res.status}`);
      return res.json();
    }

    module.exports = { fireRoutine, listProjects, signPaperclip };
    ```

    ```js
    const http = require('node:http');
    const { URL } = require('node:url');
    const filters = require('./relay-filters');
    const paperclip = require('./relay-paperclip-client');
    const dedup = require('./dedup-store');

    const MAX_BODY = 1 * 1024 * 1024;

    function readBody(req) {
      return new Promise((resolve, reject) => {
        const chunks = [];
        let size = 0;
        req.on('data', (c) => {
          size += c.length;
          if (size > MAX_BODY) { reject(Object.assign(new Error('body too large'), { code: 413 })); req.destroy(); return; }
          chunks.push(c);
        });
        req.on('end', () => resolve(Buffer.concat(chunks).toString('utf8')));
        req.on('error', reject);
      });
    }

    function log(obj) {
      process.stdout.write(JSON.stringify({ ts: new Date().toISOString(), ...obj }) + '\n');
    }

    function reply(res, code, body) {
      res.writeHead(code, { 'content-type': 'application/json' });
      res.end(JSON.stringify(body));
    }

    function buildConfig(resolver) {
      const get = (name) => {
        const v = resolver(name);
        if (!v) throw new Error(`missing credential: ${name}`);
        return v;
      };
      return {
        githubSecret: get('github_webhook_secret'),
        jiraSecret: get('jira_webhook_secret'),
        paperclipSigningKey: get('paperclip_webhook_signing_key'),
        triageUserLogin: get('github_triage_user_login'),
        triageUserAccountId: get('jira_triage_user_accountid'),
        paperclipApiBase: get('paperclip_api_base'),
        paperclipApiKey: get('paperclip_api_key'),
        paperclipCompanyId: get('paperclip_company_id'),
        routineGithub: get('paperclip_triage_routine_github'),
        routineJira: get('paperclip_triage_routine_jira'),
      };
    }

    async function handleGithub(req, res, config) {
      const rawBody = await readBody(req);
      const sig = req.headers['x-hub-signature-256'];
      if (!filters.verifyGithubSignature(rawBody, sig, config.githubSecret)) {
        log({ route: 'github', status: 401, reason: 'bad signature' });
        return reply(res, 401, { error: 'bad signature' });
      }
      const event = req.headers['x-github-event'] || 'unknown';
      const payload = JSON.parse(rawBody);
      const decision = filters.shouldRelayGithub(event, payload, { triageUserLogin: config.triageUserLogin });

      if (!decision.relay) {
        log({ route: 'github', event, relay: false, reason: decision.reason, status: 200 });
        return reply(res, 200, { ok: true, relayed: false, reason: decision.reason });
      }

      if (decision.dedupKey) {
        const existing = dedup.check(decision.dedupKey);
        if (existing) {
          log({ route: 'github', event, relay: false, reason: 'dedup hit', dedupKey: decision.dedupKey, status: 200 });
          return reply(res, 200, { ok: true, relayed: false, reason: 'dedup hit', issueId: existing.paperclipIssueId });
        }
      }

      try {
        const result = await paperclip.fireRoutine(config.routineGithub, {
          source: 'github',
          event,
          dedupKey: decision.dedupKey,
          reason: decision.reason,
          payload,
        }, { apiBase: config.paperclipApiBase, signingKey: config.paperclipSigningKey });

        if (decision.dedupKey) {
          dedup.insert(decision.dedupKey, { paperclipIssueId: result.runId, source: 'github', createdAt: new Date().toISOString() });
        }

        log({ route: 'github', event, relay: true, dedupKey: decision.dedupKey, status: 200 });
        return reply(res, 200, { ok: true, relayed: true, runId: result.runId });
      } catch (err) {
        log({ route: 'github', event, relay: true, status: 502, error: err.message });
        return reply(res, 502, { error: 'paperclip fire failed' });
      }
    }

    async function handleJira(req, res, config) {
      const rawBody = await readBody(req);
      const sig = req.headers['x-hub-signature'];
      if (!filters.verifyJiraSignature(rawBody, sig, config.jiraSecret)) {
        log({ route: 'jira', status: 401, reason: 'bad signature' });
        return reply(res, 401, { error: 'bad signature' });
      }
      const payload = JSON.parse(rawBody);
      const decision = filters.shouldRelayJira(payload, { triageUserAccountId: config.triageUserAccountId });

      if (!decision.relay) {
        log({ route: 'jira', relay: false, reason: decision.reason, status: 200 });
        return reply(res, 200, { ok: true, relayed: false, reason: decision.reason });
      }

      if (decision.dedupKey) {
        const existing = dedup.check(decision.dedupKey);
        if (existing) {
          log({ route: 'jira', relay: false, reason: 'dedup hit', dedupKey: decision.dedupKey, status: 200 });
          return reply(res, 200, { ok: true, relayed: false, reason: 'dedup hit', issueId: existing.paperclipIssueId });
        }
      }

      try {
        const result = await paperclip.fireRoutine(config.routineJira, {
          source: 'jira',
          dedupKey: decision.dedupKey,
          reason: decision.reason,
          payload,
        }, { apiBase: config.paperclipApiBase, signingKey: config.paperclipSigningKey });

        if (decision.dedupKey) {
          dedup.insert(decision.dedupKey, { paperclipIssueId: result.runId, source: 'jira', createdAt: new Date().toISOString() });
        }

        log({ route: 'jira', relay: true, dedupKey: decision.dedupKey, status: 200 });
        return reply(res, 200, { ok: true, relayed: true, runId: result.runId });
      } catch (err) {
        log({ route: 'jira', relay: true, status: 502, error: err.message });
        return reply(res, 502, { error: 'paperclip fire failed' });
      }
    }

    async function handleRequest(req, res, config) {
      if (req.method !== 'POST') return reply(res, 405, { error: 'method not allowed' });

      const ctype = req.headers['content-type'] || '';
      if (!ctype.startsWith('application/json')) return reply(res, 415, { error: 'content-type must be application/json' });

      const url = new URL(req.url, `http://${req.headers.host || 'localhost'}`);
      try {
        if (url.pathname === '/github') return await handleGithub(req, res, config);
        if (url.pathname === '/jira') return await handleJira(req, res, config);
        return reply(res, 404, { error: 'not found' });
      } catch (err) {
        if (err.code === 413) return reply(res, 413, { error: 'body too large' });
        log({ route: url.pathname, status: 500, error: err.message });
        return reply(res, 500, { error: 'internal error' });
      }
    }

    function createServer({ port = 0, keychainResolver }) {
      const config = buildConfig(keychainResolver);
      const server = http.createServer((req, res) => handleRequest(req, res, config).catch(() => {}));
      return new Promise((resolve) => {
        server.listen(port, '127.0.0.1', () => {
          const addr = server.address();
          resolve({
            port: addr.port,
            url: `http://127.0.0.1:${addr.port}`,
            stop: () => new Promise(r => server.close(r)),
          });
        });
      });
    }

    module.exports = { createServer, handleRequest, buildConfig };
    ```
