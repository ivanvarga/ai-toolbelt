Create `scripts/resolve-org.js`:
- Shebang: `#!/usr/bin/env node`
- Import `execSync` from `child_process`
- Export function `resolveOrg()` that:
  1. Runs `git remote get-url origin` with `encoding: 'utf8'`, `stdio: ['pipe', 'pipe', 'pipe']`
  2. Catches errors (no git repo, no remote) and returns `null`
  3. Parses the URL with these regex patterns in order:
     - SSH colon format `git@host:ORG/repo.git` -> match `/:([^/]+)\/[^/]+?$/` -> return capture group 1
     - HTTPS/ssh:// format `protocol://host/ORG/repo.git` -> match `/\/\/[^/]+\/([^/]+)\/[^/]+?$/` -> return capture group 1
  4. Returns `null` if no pattern matches
- CLI mode: if `require.main === module`, call `resolveOrg()`, if result is non-null write it to stdout via `process.stdout.write(result)`, otherwise exit with code 1
- `module.exports = resolveOrg;`

Create `scripts/resolve-credential.js`:
- Shebang: `#!/usr/bin/env node`
- Import `execSync` from `child_process`, `path` from `path`
- Import `resolveOrg` via `require('./resolve-org')`
- Define `KEYCHAIN` as `path.join(__dirname, 'keychain.js')`
- Define helper `keychainGet(service)` that runs `node "${KEYCHAIN}" get ${service}` with `encoding: 'utf8'`, returns trimmed stdout, catches errors and returns `null`
- Export function `getCredential(service)` that:
  1. Calls `resolveOrg()` to get org
  2. If org is non-null, tries `keychainGet(\`${service}.${org}\`)`; if found, returns it
  3. Falls back to `keychainGet(service)` (global)
  4. Returns the result (string or null)
- CLI mode: if `require.main === module`:
  - Read `process.argv[2]` as service name
  - If missing, write `'Usage: resolve-credential.js <service>\n'` to stderr and exit 1
  - Call `getCredential(service)`
  - If null, exit 1
  - Otherwise write value to stdout via `process.stdout.write(value)`
- `module.exports = { getCredential };`
