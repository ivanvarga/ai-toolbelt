Create `scripts/migrate-credentials.js`:

- Shebang: `#!/usr/bin/env node`
- Imports: `child_process.execSync`, `fs`, `path`, `os`, `readline`

- Constants:
  ```javascript
  const DEFAULT_SCAN_DIRS = [
    path.join(os.homedir(), 'Projects'),
    path.join(os.homedir(), 'Work')
  ];
  const SERVICES = ['tb.sentry-token', 'tb.github-session', 'tb.contentful-token', 'tb.jira-token'];
  const KEYCHAIN = path.join(__dirname, 'keychain.js');
  ```

- Accept additional directories as CLI arguments: `const scanDirs = process.argv.slice(2).length > 0 ? process.argv.slice(2) : DEFAULT_SCAN_DIRS;`

- Helper function `prompt(question)` using readline (same pattern as setup-credential.js).

- Helper function `keychainGet(service)` that runs `node "${KEYCHAIN}" get ${service}`, returns value or null.

- Helper function `keychainSet(service, value)` that runs `node "${KEYCHAIN}" set ${service} "${value}"`.

- Helper function `discoverOrgs(dirs)`:
  1. For each dir in dirs, check if it exists with `fs.existsSync(dir)`. Skip if not.
  2. Run `find "${dir}" -name .git -maxdepth 3 -type d` to find git repos. Parse output into array of paths.
  3. For each `.git` path, get the parent directory, then run `git -C "${parentDir}" remote get-url origin 2>/dev/null`. Catch errors.
  4. Parse org from the URL using the same regex patterns from resolve-org.js:
     - SSH colon: `/:([^/]+)\/[^/]+?$/`
     - HTTPS/ssh://: `/\/\/[^/]+\/([^/]+)\/[^/]+?$/`
  5. Build a Map of org -> array of repo paths.
  6. Return the Map.

- Main async function:
  1. Check TTY: if not interactive, print error and exit 1.
  2. Print header: `"Credential Migration: Global -> Org-Scoped\n"`
  3. Print scanning message: `"Scanning directories: ${scanDirs.join(', ')}...\n"`
  4. Call `discoverOrgs(scanDirs)`.
  5. If no orgs found, print `"No git repos with remotes found. Nothing to migrate."` and exit 0.
  6. Print summary: for each org, print `"  ${org}: ${repos.length} repo(s)"`
  7. Check which global credentials exist:
     ```javascript
     const globals = {};
     for (const service of SERVICES) {
       globals[service] = keychainGet(service);
     }
     const availableGlobals = SERVICES.filter(s => globals[s]);
     ```
  8. If no globals found, print `"No global credentials found. Nothing to migrate."` and exit 0.
  9. Print available globals: `"Global credentials available: ${availableGlobals.map(s => s.replace('tb.', '')).join(', ')}"`
  10. For each org in the discovered map:
      - Ask: `"Copy global credentials to ${org}? (y/N) "`
      - If answer is 'y' or 'Y':
        - For each service in availableGlobals:
          - Check if org-scoped key already exists: `keychainGet(\`${service}.${org}\`)`
          - If exists, print `"  ${service}.${org}: already exists, skipping"`
          - If not, copy: `keychainSet(\`${service}.${org}\`, globals[service])` and print `"  ${service}.${org}: copied"`
      - If answer is not 'y', print `"  Skipping ${org}"`
  11. Print `"\nMigration complete. Global credentials preserved as fallback."`

- Call `main().catch(err => { console.error(err.message); process.exit(1); });`
