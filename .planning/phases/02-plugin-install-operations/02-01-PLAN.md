<task type="auto">
  <name>Task 1: Create SessionStart hook registration and discovery script</name>
  <files>hooks/hooks.json, hooks/session-start.sh</files>
  <action>
Create hooks/hooks.json following the superpowers pattern exactly. Register a SessionStart hook that:
- Matches all session events: "startup|resume|clear|compact"
- Runs async (non-blocking)
- Points to "${CLAUDE_PLUGIN_ROOT}/hooks/session-start.sh"

Create hooks/session-start.sh as an executable bash script that:
1. Uses `#!/usr/bin/env bash` with `set -euo pipefail`
2. Resolves PLUGIN_ROOT from script location: `SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]:-$0}")" && pwd)"` then `PLUGIN_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"`
3. Implements escape_for_json function (from superpowers pattern) that escapes backslash, double-quote, newline, carriage return, tab using bash parameter substitution
4. Scans `${PLUGIN_ROOT}/skills/*/SKILL.md` at runtime for dynamic skill discovery
5. For each SKILL.md found, extracts `name` and `description` from YAML frontmatter using grep/sed (not a YAML parser). Strip surrounding quotes from description values. Use only the first match per field (-m1).
6. Builds a skill inventory string listing each as `- /tb:{name} -- {description}`
7. If no skills found, outputs a "No skills installed yet" message
8. Wraps the context in JSON output with hookSpecificOutput.hookEventName = "SessionStart" and hookSpecificOutput.additionalContext containing the skill inventory prefixed with a header like "tb plugin skills available:"
9. Always exits 0 (never exit non-zero from SessionStart hooks)

The hook script MUST include hookEventName in the JSON output (omitting it causes silent failure since ~v2.1.42).

Make session-start.sh executable: `chmod +x hooks/session-start.sh`

Remove hooks/.gitkeep since hooks/ now has real content.
  </action>
