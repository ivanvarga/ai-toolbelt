- name: update
- description: Pull latest tb plugin changes, show changelog, and remind to reload
- disable-model-invocation: true (user-initiated only, has side effects)

Skill instructions (the markdown body that Claude reads and follows):

The skill instructs Claude to perform these steps:

1. **Detect environment**: Determine if running from plugin cache (`~/.claude/plugins/cache/...`) or from source (git repo). Check if `${CLAUDE_SKILL_DIR}/../../.git` exists. If from cache (no .git), tell the user to run `claude plugin update tb@tb-marketplace` instead and remind to `/reload-plugins`, then stop.

2. **Capture current version**: Read version from `${CLAUDE_SKILL_DIR}/../../.claude-plugin/plugin.json` before pulling.

3. **Stash local changes**: Run `git stash --include-untracked -q 2>/dev/null || true` to handle dirty working tree.

4. **Pull latest**: Run `git pull --rebase origin main` from the plugin root directory.

5. **Handle stash pop**: Run `git stash pop -q 2>/dev/null || true`. If stash pop fails (exit code non-zero), warn the user that stashed changes conflicted and they need to resolve manually -- the stash is preserved.

6. **Compare versions**: Read version again from plugin.json. If version changed, show "Updated: {old} -> {new}".

7. **Show changelog**: Run `git log --oneline {old_commit}..HEAD` to show what changed. Use the commit hash captured before pull, not version string, for accurate log. Alternatively, show `git diff --stat HEAD@{1}..HEAD` to show files changed.

8. **Remind to reload**: Tell the user to run `/reload-plugins` to pick up changes.

All bash commands in the skill should use `${CLAUDE_SKILL_DIR}/../..` to resolve plugin root (CLAUDE_SKILL_DIR resolves to skills/update/, going up two levels reaches plugin root).

Remove skills/.gitkeep since skills/ now has real content.

**Part A: Create check scripts in scripts/checks/**

Create scripts/checks/ directory.

Each check script follows the convention: receives $1 = PLUGIN_ROOT, outputs "PASS|FAIL check-name message", always exits 0.

1. **scripts/checks/plugin-registered.sh**: Check if the tb plugin is registered.
   - Check `~/.claude/settings.json` for "tb" in enabledPlugins OR check `~/.claude/plugins/installed_plugins.json` for "tb"
   - PASS if found in either, FAIL with hint to run the install commands if not found

2. **scripts/checks/skills-valid.sh**: Check that all skill directories have valid SKILL.md.
   - Glob `${PLUGIN_ROOT}/skills/*/`
   - For each directory (skip .gitkeep), check SKILL.md exists and has `name:` in frontmatter
   - PASS with count of valid skills if all good, FAIL listing directories missing SKILL.md

3. **scripts/checks/hooks-valid.sh**: Check hooks configuration.
   - Verify `${PLUGIN_ROOT}/hooks/hooks.json` exists and is valid JSON (use python3 -c "import json; json.load(open('...'))")
   - Verify each script referenced in hooks.json command fields exists and is executable
   - PASS if all hooks valid, FAIL with specific issue

Make all check scripts executable: `chmod +x scripts/checks/*.sh`

Remove scripts/.gitkeep since scripts/ now has real content.
