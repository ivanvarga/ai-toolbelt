**Script structure:**

```
#!/usr/bin/env bash
PLUGIN_ROOT="${1:-.}"
```

**Check 1: hooks.json registration**
Use python3 to check if `UserPromptSubmit` key exists in hooks.json (same technique as hooks-valid.sh):
```
HOOKS_JSON="${PLUGIN_ROOT}/hooks/hooks.json"
```
Run: `python3 -c "import json; d=json.load(open('${HOOKS_JSON}')); assert 'UserPromptSubmit' in d.get('hooks', d)" 2>/dev/null`

If this fails, check settings.json fallback before reporting FAIL:
```
SETTINGS_JSON="${HOME}/.claude/settings.json"
```
Run: `python3 -c "import json; d=json.load(open('${SETTINGS_JSON}')); assert 'UserPromptSubmit' in d.get('hooks', {})" 2>/dev/null`

If settings.json has it: output `PASS user-prompt-hook UserPromptSubmit registered in settings.json (fallback mode)` and continue to Check 2.
If neither has it: output `FAIL user-prompt-hook UserPromptSubmit hook not registered in hooks.json or settings.json` and `exit 0`.

**Check 2: script file exists**
Extract the command from whichever registration was found. For hooks.json:
```
COMMAND=$(python3 -c "
import json
d = json.load(open('${HOOKS_JSON}'))
hooks_section = d.get('hooks', d)
ups = hooks_section.get('UserPromptSubmit', [])
for m in ups:
    for h in m.get('hooks', []):
        cmd = h.get('command', '')
        if cmd:
            print(cmd)
            break
    break
" 2>/dev/null)
```

Resolve the path (replace `${CLAUDE_PLUGIN_ROOT}` with `$PLUGIN_ROOT`, strip the `node ` prefix):
```
RESOLVED="${COMMAND/\$\{CLAUDE_PLUGIN_ROOT\}/${PLUGIN_ROOT}}"
SCRIPT_PATH=$(echo "$RESOLVED" | sed 's/^node //')
```

If `[ -f "$SCRIPT_PATH" ]`: output `PASS user-prompt-hook UserPromptSubmit hook registered and script exists`
If not: output `FAIL user-prompt-hook UserPromptSubmit hook registered but script missing at ${SCRIPT_PATH}`

Always `exit 0` at the end (doctor checks never exit nonzero).

**File must be executable:** `chmod +x scripts/checks/user-prompt-hook.sh`

### 5. Verify UserPromptSubmit hook output capture

The UserPromptSubmit hook auto-injects Forgetful memories into every prompt. Due to bug #12151, plugin hooks.json output may be silently discarded. This step checks if fallback registration in settings.json is needed.

First, check if the hook is already registered in settings.json:

\```bash
SETTINGS_JSON="$HOME/.claude/settings.json"
if [ -f "$SETTINGS_JSON" ] && python3 -c "import json; d=json.load(open('$SETTINGS_JSON')); assert 'UserPromptSubmit' in d.get('hooks', {})" 2>/dev/null; then
  echo "UserPromptSubmit: already registered in settings.json (fallback mode active)"
else
  echo "UserPromptSubmit: using plugin hooks.json registration (primary mode)"
  echo "If Forgetful context is not appearing in prompts, run this step manually to enable fallback."
fi
\```

- If already in settings.json: report "UserPromptSubmit: fallback mode active" and continue to step 6.
- If NOT in settings.json (primary mode): Tell the user that the hook is registered via plugin hooks.json. Explain that if they notice Forgetful context is NOT appearing in their prompts (after verifying Forgetful is reachable with `/tb:doctor`), they should ask Claude to "register the UserPromptSubmit hook in settings.json as a fallback". Provide the fallback registration command:

  \```bash
  PLUGIN_ROOT="${CLAUDE_SKILL_DIR}/../.."
  ABSOLUTE_HOOK="$(cd "$PLUGIN_ROOT" && pwd)/hooks/user-prompt-context.js"
  SETTINGS_JSON="$HOME/.claude/settings.json"

  if [ ! -f "$SETTINGS_JSON" ]; then
    echo '{}' > "$SETTINGS_JSON"
  fi

  python3 -c "
  import json
  with open('$SETTINGS_JSON') as f:
      settings = json.load(f)
  hooks = settings.setdefault('hooks', {})
  hooks['UserPromptSubmit'] = [{'hooks': [{'type': 'command', 'command': 'node $ABSOLUTE_HOOK', 'timeout': 10}]}]
  with open('$SETTINGS_JSON', 'w') as f:
      json.dump(settings, f, indent=2)
  "
  echo "UserPromptSubmit: registered in settings.json as fallback"
  \```

  After running the fallback registration, verify:

  \```bash
  python3 -c "import json; d=json.load(open('$SETTINGS_JSON')); assert 'UserPromptSubmit' in d.get('hooks', {}); print('Verified: UserPromptSubmit in settings.json')" 2>/dev/null || echo "ERROR: Registration failed"
  \```
