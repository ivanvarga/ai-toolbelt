Create `hooks/user-prompt-context.js` as a Node.js script (shebang: `#!/usr/bin/env node`). The script reads UserPromptSubmit stdin JSON, queries Forgetful for relevant memories, and outputs additionalContext JSON to stdout.

**Structure (follow gsd-project-context.js patterns exactly):**

1. **Requires:** `child_process` (execSync), `fs`, `os`, `path`, and `require('../scripts/forgetful-client')` for `resolveForgetfulUrl`, `createSession`, `callTool`.

2. **readStdin()** -- async function that collects all stdin chunks and returns the concatenated string:
   ```
   async function readStdin() {
     const chunks = [];
     for await (const chunk of process.stdin) chunks.push(chunk);
     return Buffer.concat(chunks).toString();
   }
   ```

3. **extractRepoName()** -- Copy from gsd-project-context.js exactly:
   ```
   execSync('git remote get-url origin 2>/dev/null', { encoding: 'utf8' })
     .trim()
     .replace(/.*[:/]([^/]+\/[^/]+?)(?:\.git)?$/, '$1')
   ```

4. **parseMemories(result)** -- Copy from gsd-project-context.js exactly:
   ```
   result?.result?.structuredContent?.primary_memories
     || JSON.parse(result?.result?.content?.[0]?.text || '{}').primary_memories
     || []
   ```

5. **isTrivialPrompt(prompt)** -- per D-01/D-02: Return true if prompt length < 20 AND matches a trivial pattern. Trivial patterns (case-insensitive, trimmed): `yes`, `no`, `ok`, `okay`, `y`, `n`, `continue`, `do it`, `go ahead`, `sounds good`, `sure`, `yep`, `nope`, `thanks`, `thank you`, `got it`, `done`, `next`, `lgtm`, `approved`, `looks good`, `go for it`, `please`, `right`.

6. **Session failure flag** -- per D-06/D-07:
   - Flag file path: `path.join(os.tmpdir(), 'tb-forgetful-failed-' + process.ppid)` (use ppid to scope to Claude session)
   - Check: if flag file exists, `process.exit(0)` immediately (skip all Forgetful calls for rest of session)
   - Set: on first catch of any Forgetful error, write flag file, then output a one-time additionalContext notice:
     ```
     hookSpecificOutput: {
       hookEventName: 'UserPromptSubmit',
       additionalContext: '[Forgetful auto-context] Forgetful is unreachable -- auto-context disabled for this session. Use /tb:load-context for manual memory retrieval.'
     }
     ```
   - On subsequent failures: flag file exists, so script exits at step 6 check before any API call.

7. **Project ID cache** -- per D-08/D-09:
   - Cache file path: `path.join(os.tmpdir(), 'tb-project-' + repoName.replace(/\//g, '-') + '.json')`
   - Read cache: try `JSON.parse(fs.readFileSync(cacheFile, 'utf8'))`. If `cached.repoName === repoName && Date.now() - cached.ts < 3600000` (1 hour TTL per D-09 discretion), return `cached.projectId`.
   - Write cache: after resolving project ID, `fs.writeFileSync(cacheFile, JSON.stringify({ repoName, projectId, ts: Date.now() }))`.

8. **resolveProjectId(url, sessionId, repoName)** -- follows gsd-project-context.js:
   - First check cache (step 7). If hit, return cached ID.
   - Call `callTool(url, sessionId, 'execute_forgetful_tool', { tool_name: 'list_projects', arguments: { repo_name: repoName } })`.
   - Parse projects same as gsd-project-context.js: `result?.result?.structuredContent?.projects || JSON.parse(result?.result?.content?.[0]?.text || '{}').projects || []`.
   - If `projects.length > 0`, cache `projects[0].id` and return it. Otherwise return null.

9. **main()** function flow:
   a. Read stdin, parse JSON: `const input = JSON.parse(await readStdin()); const prompt = (input.prompt || '').trim();`
   b. Skip if prompt empty: `if (!prompt) process.exit(0);`
   c. Skip /gsd: and /tb:load-context prompts per CTXI-06: `if (/^\/?gsd:|^\/?tb:load-context/i.test(prompt)) process.exit(0);`
   d. Skip trivial prompts per D-01/D-02: `if (isTrivialPrompt(prompt)) process.exit(0);`
   e. Check session failure flag (step 6). If exists, exit 0.
   f. Resolve Forgetful URL: `const url = resolveForgetfulUrl(); if (!url) process.exit(0);`
   g. Extract repo name. If fails, exit 0.
   h. Create session: `const sessionId = await createSession(url);`
   i. Resolve project ID (with caching). If null, exit 0.
   j. Query memories: `callTool(url, sessionId, 'execute_forgetful_tool', { tool_name: 'query_memory', arguments: { query: prompt, query_context: 'auto-inject: relevant project context', k: 5, project_ids: [projectId], include_links: false } })`
   k. Parse memories, filter by importance >= 7 per CTXI-05: `parseMemories(result).filter(m => m.importance >= 7)`
   l. If no memories pass filter, exit 0.
   m. Format output per CTXI-02 -- XML-tagged compact snippets:
      ```
      const context = [
        '<forgetful_context>',
        'Relevant memories from Forgetful (' + memories.length + ' found):',
        '',
        ...memories.map(m => {
          const snippet = (m.content || '').substring(0, 300);
          return '- **' + m.title + '** (importance: ' + m.importance + '): ' + snippet + '...';
        }),
        '</forgetful_context>'
      ].join('\n');
      ```
   n. Output hookSpecificOutput JSON per CTXI-02:
      ```
      process.stdout.write(JSON.stringify({
        hookSpecificOutput: {
          hookEventName: 'UserPromptSubmit',
          additionalContext: context
        }
      }));
      ```

10. **Error handling** -- per CTXI-03: `main().catch(() => process.exit(0));`
    BUT: wrap the Forgetful API calls (steps h-k) in a try/catch that sets the failure flag and outputs the one-time notice (step 6) before exiting. The outer `.catch()` handles truly unexpected errors silently.

**Implementation detail for failure notice (combining steps 6 and 10):**
Inside main(), wrap steps f-n in try/catch. On catch:
  - Check if flag file already exists. If yes, just `process.exit(0)` (not first failure).
  - If no flag file: write it, then output one-time notice via additionalContext, then `process.exit(0)`.

The outer `main().catch(() => process.exit(0))` catches anything that leaks (stdin parse errors, etc.) silently.

**File must be executable:** `chmod +x hooks/user-prompt-context.js`
