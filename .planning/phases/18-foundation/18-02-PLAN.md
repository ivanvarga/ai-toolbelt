**File 2: scripts/checks/forgetful-mcp.sh** (per D-04, D-02, FNDTN-02)

```bash
#!/usr/bin/env bash
PLUGIN_ROOT="${1:-.}"

FORGETFUL_URL=$(jq -r '.mcpServers.forgetful.url // empty' ~/.claude.json 2>/dev/null)

if [ -z "$FORGETFUL_URL" ]; then
    echo "FAIL forgetful-mcp Forgetful MCP not configured in ~/.claude.json. Run: claude mcp add forgetful --scope user --transport http <url>"
    exit 0
fi

if curl -s -m 3 -o /dev/null -w "" -X POST \
    -H "Content-Type: application/json" \
    -H "Accept: application/json, text/event-stream" \
    -d '{"jsonrpc":"2.0","method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"tb-health","version":"0.1.0"}},"id":1}' \
    "$FORGETFUL_URL" 2>/dev/null; then
    echo "PASS forgetful-mcp Forgetful reachable at ${FORGETFUL_URL}"
else
    echo "WARN forgetful-mcp Forgetful configured but unreachable at ${FORGETFUL_URL}"
fi
exit 0
```

- Reads URL from `~/.claude.json` via `jq -r '.mcpServers.forgetful.url // empty'` (per D-02, Pitfall 6)
- Missing config = FAIL (not configured at all)
- Config present but unreachable = WARN (server may be down, not a plugin problem)
- Uses curl with `-m 3` timeout, sends actual MCP initialize request (not just TCP connect)
- Both required headers included: Content-Type AND Accept with text/event-stream (Pitfall 2)

**File 3: scripts/checks/forgetful-plugin.sh** (per D-04, FNDTN-03)

```bash
#!/usr/bin/env bash
PLUGIN_ROOT="${1:-.}"

INSTALLED_FILE="$HOME/.claude/plugins/installed_plugins.json"

if [ -f "$INSTALLED_FILE" ] && jq -e '.[] | select(.id == "forgetful-plugin@forgetful-plugins")' "$INSTALLED_FILE" >/dev/null 2>&1; then
    echo "PASS forgetful-plugin forgetful-plugin installed"
else
    echo "FAIL forgetful-plugin forgetful-plugin not installed. Run: /tb:bootstrap"
fi
exit 0
```

- Reads `~/.claude/plugins/installed_plugins.json` directly (per Pitfall 5 -- avoids slow CLI)
- Uses jq to match plugin by ID `forgetful-plugin@forgetful-plugins`
- FAIL fix hint points to /tb:bootstrap (the skill that will install it in Phase 20)
