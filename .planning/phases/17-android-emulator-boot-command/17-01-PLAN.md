**android.py** -- Add the following functions at the top of the file (after existing imports, before `require_adb`):

Add new imports at top: `import os`, `import time` (re, shutil, subprocess already imported).

1. `_find_emulator()` -- Find the `emulator` binary:
   - Try `shutil.which("emulator")` first
   - Fall back to `os.environ.get("ANDROID_HOME")` or `os.environ.get("ANDROID_SDK_ROOT")`, then check `os.path.join(android_home, "emulator", "emulator")`
   - Return path string or None

2. `require_emulator()` -- Raise RuntimeError if emulator not found:
   - Call `_find_emulator()`, if None raise `RuntimeError("Android emulator not found. Install via Android Studio SDK Manager or set ANDROID_HOME environment variable.")`
   - Return path

3. `_parse_emulator_version(emulator_path)` -- Parse version tuple from `emulator -version`:
   - Run `subprocess.run([emulator_path, "-version"], capture_output=True, text=True)`
   - Regex: `r"Android emulator version (\d+)\.(\d+)\.(\d+)"`
   - Return tuple `(major, minor, patch)` or None if no match

4. `list_avds()` -- List available AVDs:
   - Call `require_emulator()` to get path
   - Run `subprocess.run([emulator_path, "-list-avds"], capture_output=True, text=True)`
   - If returncode != 0, return empty list
   - Parse each non-empty stripped line as an AVD name
   - Return list of dicts: `{"name": avd_name, "platform": "android", "type": "emulator", "state": "available"}`

5. `_launch_emulator(emulator_path, avd_name, gpu_mode)` -- Launch emulator process:
   - Use `subprocess.Popen([emulator_path, "-avd", avd_name, "-gpu", gpu_mode], stdout=subprocess.DEVNULL, stderr=subprocess.PIPE)`
   - Return the Popen object

6. `_wait_for_process_stable(proc, seconds=5)` -- Wait for process to stabilize:
   - Use `time.monotonic()` deadline loop
   - Poll with `proc.poll()` every 0.5s
   - Return True if process still alive after `seconds`, False if it exited

7. `_get_emulator_serials()` -- Get set of current emulator-* serials from `adb devices`:
   - Run `subprocess.run(["adb", "devices"], capture_output=True, text=True, timeout=5)`
   - Parse lines after header, collect serials matching `emulator-\d+` pattern
   - Catch TimeoutExpired and RuntimeError, return empty set on failure

8. `_wait_for_boot(device_serial, timeout)` -- Poll sys.boot_completed:
   - Use `time.monotonic()` deadline loop with 2s polling interval
   - Run `subprocess.run(["adb", "-s", device_serial, "shell", "getprop", "sys.boot_completed"], capture_output=True, text=True, timeout=5)`
   - Check `result.stdout.strip() == "1"` (strip handles \r\n)
   - Catch subprocess.TimeoutExpired and RuntimeError (device not yet available)
   - Return True if booted, False on timeout

9. `boot_emulator(avd_name, timeout=120)` -- Full boot sequence:
   - Call `require_emulator()` for path
   - Call `_parse_emulator_version(emulator_path)`, check version >= (36, 4, 9). If not, raise `RuntimeError(f"Android emulator 36.4.9+ required (found {'.'.join(map(str, version)) if version else 'unknown'}). Update via Android Studio SDK Manager.")`
   - Snapshot serials before launch: `before = _get_emulator_serials()`
   - Try `-gpu host` first via `_launch_emulator`, check stable via `_wait_for_process_stable(proc, 5)`
   - If unstable (returns False), set `gpu_mode = "software"`, launch again. If still unstable, raise `RuntimeError("Emulator failed to start with both host and software GPU modes")`
   - Detect new serial: poll `_get_emulator_serials() - before` in a loop with 2s interval and `timeout` deadline until a new serial appears. If no new serial within timeout, raise `RuntimeError("Emulator started but no adb device detected")`
   - Call `_wait_for_boot(device_serial, remaining_timeout)` where remaining_timeout = deadline - monotonic
   - Build result: `{"id": device_serial, "status": "booted" if booted else "timeout", "gpu_mode": gpu_mode}`
   - If `gpu_mode == "software"`, add `"note": "Hardware GPU unavailable, using software rendering (slower)"`
   - If not booted, raise `RuntimeError(f"Emulator boot timed out after {timeout}s (left running)")`
   - Return result dict

**1. Rewrite `boot` command** (D-02, D-04, D-17, D-18):

Replace the current `boot` command entirely:

```python
@device.command()
@click.argument("device_id")
@click.option("--timeout", type=int, default=120, help="Boot timeout in seconds (Android only)")
def boot(device_id, timeout):
    """Boot a device (iOS simulator or Android emulator)."""
    ios_error = None
    try:
        result = ios.boot_device(device_id)
        output(result)
        return
    except RuntimeError as e:
        ios_error = e

    android_error = None
    try:
        avds = android.list_avds()
        avd_names = [a["name"] for a in avds]
        if device_id in avd_names:
            result = android.boot_emulator(device_id, timeout=timeout)
            output(result)
            return
    except RuntimeError as e:
        android_error = e

    if ios_error and android_error:
        error(f"Boot failed. iOS: {ios_error} | Android: {android_error}")
    elif ios_error:
        error(f"iOS boot failed: {ios_error}")
    elif android_error:
        error(f"Android boot failed: {android_error}")
    else:
        error(f"Device not found: {device_id}")
```

Key changes per decisions:
- D-02: Takes device_id which is AVD name for Android (same pattern as iOS simulator ID)
- D-04: `--timeout` flag with 120s default
- D-17: No bare `except RuntimeError: pass` -- errors captured and propagated
- D-18: Try iOS first, then Android. Propagate actual errors from both.
- D-06: Returns result JSON on success, error on failure (silent during boot)
- D-07: On timeout, `boot_emulator` raises RuntimeError but leaves process running

**2. Add `--available` flag to `list_devices`** (D-01, D-03):

Update the `list_devices` command:

```python
@device.command("list")
@click.option("--platform", type=click.Choice(["ios", "android"]), help="Filter by platform")
@click.option("--available", is_flag=True, default=False, help="Include available but unbooted devices")
def list_devices(platform, available):
    """List connected iOS simulators and Android emulators."""
    devices = []

    if platform == "ios" or platform is None:
        try:
            devices.extend(
                _strip_internal(d) for d in ios.list_devices()
            )
        except RuntimeError as e:
            if platform == "ios":
                error(str(e))

    if platform == "android" or platform is None:
        try:
            devices.extend(android.list_devices())
        except RuntimeError as e:
            if platform == "android":
                error(str(e))

    if available:
        if platform == "android" or platform is None:
            try:
                running_ids = {d["id"] for d in devices if d.get("platform") == "android"}
                for avd in android.list_avds():
                    if avd["name"] not in running_ids:
                        devices.append(avd)
            except RuntimeError:
                pass

    output(devices)
```

Key: D-01 adds `--available` flag. D-03 distinguishes available AVDs (state: "available") from running emulators (state: "booted"). Only Android AVDs are added (iOS simulators already show all states via simctl).
