    1. Create `tools/mbridge/src/mbridge/parsing/ios_parser.py`:
       - `parse_ios_dump(elements, screen_width, screen_height)` -- takes the raw list of dicts from idb describe-all output. For each element:
         - type: normalize_type(element.get("type", "Other"), IOS_TYPE_MAP)
         - label: element.get("AXLabel", "") or ""
         - accessibility_id: element.get("AXUniqueId", "") or ""
         - bounds: extract from element["frame"] dict (keys: x, y, width, height) -- round float values to int
         - center: compute_center(bounds)
         - enabled: element.get("enabled", False)
         - visible: is_visible(bounds, screen_width, screen_height)
         - children: [] (flat list, per idb limitation)
       - Handle missing "frame" gracefully: skip element or use zero bounds
       - Return list of normalized element dicts

    2. Create `tools/mbridge/src/mbridge/parsing/android_parser.py`:
       - Import xml.etree.ElementTree as ET, re
       - `parse_android_dump(xml_string, screen_width, screen_height)` -- parses XML string, strips trailing "UI hierchary dumped to: /dev/tty" if present by finding "</hierarchy>" and truncating. Calls `_parse_node` on each child of the root hierarchy element. Returns list of top-level normalized elements.
       - `_parse_node(node, screen_width, screen_height)` -- recursive:
         - type: normalize_type(node.get("class", ""), ANDROID_TYPE_MAP)
         - label: node.get("text", "") or ""
         - accessibility_id: node.get("content-desc", "") or _strip_resource_id(node.get("resource-id", ""))
         - bounds: parse_android_bounds(node.get("bounds", ""))
         - center: compute_center(bounds) if bounds else {"x": 0, "y": 0}
         - enabled: node.get("enabled", "false") == "true"
         - visible: is_visible(bounds, screen_width, screen_height) if bounds else False
         - children: [_parse_node(child, screen_width, screen_height) for child in node]
       - `_strip_resource_id(rid)` -- if rid contains ":", return part after last ":" (strips package prefix like "com.example:id/btn_login" -> "btn_login"), else return rid
