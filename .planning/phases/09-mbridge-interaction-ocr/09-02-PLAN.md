    - ocr_screenshot on iOS calls ios.screenshot with temp file, loads with PIL, runs pytesseract, cleans up temp file
    - ocr_screenshot on Android calls android.screenshot_bytes, loads bytes with PIL via BytesIO, runs pytesseract
    - ocr_screenshot cleans up temp file even when pytesseract raises an error (iOS path)
    - verify text with substring match returns {"found": true, "text": "matched"} when expected text appears in OCR output
    - verify text returns {"found": false, "expected": "...", "ocr_text": "full output"} when text not found
    - verify text with --exact returns found:true only when OCR output stripped equals expected text
    - verify text with --exact returns found:false when OCR output contains expected text but has other text too
    - require_tesseract raises RuntimeError when tesseract binary not found
    - ios.screenshot calls xcrun simctl io <device_id> screenshot <dest_path>
    - android.screenshot_bytes calls adb -s <device_id> exec-out screencap -p and returns stdout bytes
  </behavior>
  <action>
    **Dependencies (pyproject.toml):**
    Add `pytesseract>=0.3.13` and `Pillow>=12.0` to the `dependencies` list alongside existing `click>=8.0`.

    **Platform screenshot functions:**

    In ios.py, add `screenshot(device_id, dest_path)`: calls `require_xcrun()` then `run_cmd(["xcrun", "simctl", "io", device_id, "screenshot", dest_path])`.

    In android.py, add `screenshot_bytes(device_id)`: calls `require_adb()` then `subprocess.run(["adb", "-s", device_id, "exec-out", "screencap", "-p"], capture_output=True)`. Check returncode != 0 -> raise RuntimeError. Return `result.stdout` (raw bytes). Note: this function must NOT use `text=True` since we need binary output.

    **OCR module (new file: ocr.py):**
    Import `os`, `io`, `tempfile`, `shutil`. Import `Image` from `PIL` and `pytesseract`.

    Add `require_tesseract()`: check `shutil.which("tesseract")`, raise RuntimeError with install instructions (`brew install tesseract`) if not found.

    Add `ocr_screenshot(device_id, platform)`:
    - Call `require_tesseract()`
    - If platform == "ios": create temp file with `tempfile.NamedTemporaryFile(suffix=".png", delete=False)`, get path, call `ios.screenshot(device_id, tmp_path)`, open with `Image.open(tmp_path)`, run `pytesseract.image_to_string(img)`, delete temp file in finally block.
    - If platform == "android": call `android.screenshot_bytes(device_id)`, open with `Image.open(io.BytesIO(raw))`, run `pytesseract.image_to_string(img)`.
    - Return the OCR text string.

    **Verify text subcommand (verify.py):**
    Import `_detect_platform` from `mbridge.device`, `output`/`error` from `mbridge.output`, `ocr_screenshot` from `mbridge.ocr`.

    Add `text` subcommand under `verify_group`:
    - Arguments: `device_id` (required), `expected` (required).
    - Options: `--exact` (flag, default False).
    - Logic: detect platform, if None error. Call `ocr_screenshot(device_id, platform)`. If `--exact`: strip OCR text, compare stripped to expected. If match: `output({"found": True, "text": expected})`. If not: `output({"found": False, "expected": expected, "ocr_text": ocr_text})`. If not `--exact`: check if expected is substring of ocr_text. Same output format.
    - Wrap in try/except RuntimeError -> error(str(e)).

    **Tests (test_verify.py):**
    Mock `pytesseract.image_to_string`, `PIL.Image.open`, platform screenshot functions, `shutil.which`, and `_detect_platform`.

    Test cases:
    - `ocr_screenshot` iOS path: mock ios.screenshot + Image.open + pytesseract -> returns OCR text, verifies temp file cleanup
    - `ocr_screenshot` Android path: mock android.screenshot_bytes + Image.open via BytesIO + pytesseract -> returns OCR text
    - `require_tesseract` raises when `shutil.which` returns None
    - Verify text substring match found -> correct output dict
    - Verify text substring not found -> output with full OCR text
    - Verify text exact match found -> correct output
    - Verify text exact match not found (substring present but not exact) -> correct output
    - Verify text strips whitespace from OCR output for exact matching
