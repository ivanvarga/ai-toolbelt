<interfaces>
Known risk areas for iOS testing (from RESEARCH.md):
- iOS backspace clear: 500 individual key presses, potentially very slow
- iOS idb coordinate space: tap coordinates may not match describe-all coordinates
- iOS flat children: idb returns flat list, no parent-child hierarchy
- idb compatibility with real devices: may need --udid flag or different connection setup
- Pixel density coords: coordinate mismatch between find results and tap targets on @2x/@3x devices

Test environment variables:
- MBRIDGE_TEST_DEVICE: iOS simulator or real device UDID
- MBRIDGE_TEST_BUNDLE: fitlumen bundle ID (e.g., com.fitlumen.app or similar)

Test command:
```bash
cd tools/mbridge && MBRIDGE_TEST_DEVICE=<id> MBRIDGE_TEST_BUNDLE=<bundle> uv run pytest tests/ -x -v
```
</interfaces>
