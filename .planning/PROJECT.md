# ai-toolbelt

## What This Is

A private Claude Code plugin that packages all of Ivan's custom skills, CLI tools, global config, and dev machine setup into a single distributable repo. 18 skills in unified SKILL.md format, org-scoped credential management via macOS Keychain, mbridge for mobile automation, and deep GSD + Forgetful integration for automatic context injection and persistent memory across AI-assisted development sessions.

## Core Value

One repo, one install command — every custom skill, credential setup, and dev tool available on any machine, always up to date.

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Private plugin over npm package | Plugin system is native to Claude Code, git-based fits private repo | ✓ Good |
| Python for mbridge | Proven by rn-debugger MCP, good ecosystem for device automation | ✓ Good |
| UI dumps + OCR over screenshots | Faster, more reliable, leverages code knowledge | ✓ Good |
| Keychain for all credentials | Secure, native macOS, gh-upload already proves the pattern | ✓ Good |
| Fresh mbridge rewrite | Previous attempt was poorly structured, clean slate needed | ✓ Good |
| All-in-one repo | Private toolkit, no need to separate work vs personal | ✓ Good |
| All items as skills, not commands | Claude Code merged commands into skills; skills support frontmatter + supporting files | ✓ Good |
| Organize conversion by complexity | Simple vs complex is more natural than origin-based grouping | ✓ Good |
| Hyphens in skill names | Plugin uses family-action pattern with hyphens (not colons) | ✓ Good |
| Org-scoped credentials | Auto-detect org from git remote, store to tb.{service}.{org} | ✓ Good |
| No unit tests for mbridge | Integration tests via subprocess.run against installed binary | ✓ Good |
| GPU host-then-software fallback | Emulator boot tries host GPU first, falls back to software on crash | ✓ Good |
| Native fetch + SSE for MCP client | No http module or EventSource dependency, lighter footprint | ✓ Good |
| Sed/awk patches over GSD fork | Non-invasive, survives GSD updates, auto-reapplied by /tb:update | ✓ Good |
| Deterministic curation over LLM | Researcher applies judgment; curation is mechanical dedup + save | ✓ Good |
| SubagentStop hook for curation | Runs async without modifying GSD workflow orchestration logic | ✓ Good |
| bin/ wrappers over symlinks | Plugin cache copies files; wrappers are explicit with dirname-relative paths | ✓ Good |

## Constraints

- **Distribution**: Must work as Claude Code private plugin (git-based)
- **Privacy**: Private GitHub repo — contains work-specific references and credentials setup
- **Credentials**: All secrets via macOS Keychain — never stored in repo or env files
- **mbridge language**: Python with uv + Click
- **mbridge approach**: UI dumps + OCR, no screenshot-based vision
- **Skill format**: All items use unified SKILL.md + frontmatter format
